健康管理助手——自定义AI智能体[网页地址https://solwell.netlify.app/]
一款基于 Flask 框架和智谱 AI 大模型（GLM-4-Flash）开发的智能健康管理应用，为用户提供一站式的个性化健康服务。
一、核心功能 ：
1.🥗 饮食建议 ：支持减脂、增肌、均衡饮食等多种方案，提供科学的餐单设计和营养搭配建议
2.🏋️ 运动计划 ：涵盖初学者、进阶、减脂等训练计划，包含有氧运动、力量训练和柔韧性训练指导
3.🔔 健康提醒 ：提供饮水、活动、护眼、睡眠等定时提醒服务，帮助用户养成良好生活习惯
4.💬 智能对话 ：基于自然语言交互，通过关键词意图识别精准匹配服务，支持复杂健康问题的AI自动回答
二、技术亮点 ：
1.采用 意图识别 技术，自动识别用户需求并调用相应知识库
2.内置结构化 知识库 （饮食知识、运动知识、健康知识），支持快速响应
3.对话记录 本地存储 （localStorage），保障用户隐私安全
4.支持 Netlify 一键部署 ，通过 Netlify Functions 解决 CORS 跨域问题
5.提供 本地开发 （Flask）和 线上部署 两种运行模式
